# GRAND THEFT: TEXT

> 你是一个靠手艺吃饭的偷车贼，而手艺正在过时。

文本驱动的犯罪经营 + 叙事模拟。浏览器运行，无引擎、无后端、无外部素材。

当前进度：**可玩的第一小时垂直切片**（第 1–12 天）。

```bash
npm install
npm run dev      # 开发
npm test         # 单测
npm run build    # 构建静态站点到 dist/
```

## 三根支柱

1. **手艺是有质感的** —— 偷一辆车是四个阶段、四次判断，每次判断前你只能看到不完整的征兆。
2. **你永远不知道谁在说真话** —— 情报会错。有时因为对方在骗你，有时因为对方自己也不知道。
   **这两种错必须能被区分，因为应对方式完全相反。**
3. **时代不会让你失败，它只是让能容下你的地方越来越小** —— 主题不靠台词说出口，
   靠可下手车辆池逐年萎缩让玩家自己算出来。

## 架构

```
src/engine/     纯逻辑，零 DOM，可单测：状态、可播种 RNG、事件日志、存档与迁移
src/systems/    玩法规则：判定公式、SegmentRun、情报、经济、热度、解锁、回合推进
src/content/    带类型的数据常量，零逻辑
src/ui/         唯一接触 DOM 的一层，含程序化 SVG 美术
```

依赖方向单向向下。`content` 不 import `systems`。

三个不可动摇的约定：

- **事件日志是唯一真相源。** 档案库是从它派生的索引，不是第二份存储——所以
  「这条情报导致了什么」是一次图遍历，永远不可能和实际发生的事对不上。
- **所有随机数走 `engine/rng.ts`。** 存档只存 `{seed, step}`，同一个种子得到完全相同的一局。
- **判定概率永远夹在 0.05–0.95 之间。** 永远有意外，也永远有希望。教学关也不例外。

## 美术

没有任何图片文件——构建产物里一张图都没有。车辆侧影、人物肖像、城市地图
全部是运行时生成的 SVG，音效是 WebAudio 现场合成。

人物用**警方拼图式合成头像**：五官由角色 id 哈希决定，同一个人永远同一张脸。
这既是对生成器能力的诚实，也正好是这个游戏的语域——本作的核心物件就是一份案卷。
