# jpfetest — 基本情報技術者試験（FE）CBT 模擬試験システム

スマートフォンでも PC でも動く、実際の CBT 画面に近い操作感の模擬試験システムです。
**出題は IPA が公式に公開している過去問題のみ**を使用し、問題文は一切改変しません。

> 中文说明：这是「基本情報技術者試験」的 CBT 模拟考试系统。**题目全部来自 IPA 官方公开的历年真题**，
> 每题都带可追溯的出典（官方 PDF 的 URL + 页码 + SHA256），绝不自行编造题目。

---

## 出題範囲（すべて IPA 公式公開資料）

| プール | 内容 | 公開されている回数 |
|---|---|---|
| `fe-honshiken` | FE 本試験 午前（平成21年度 春 〜 令和元年度 秋） | 22 回 |
| `fe-menjo` | 科目A試験免除制度の修了試験（特例措置問題） | 71 回 |
| `fe-koukai` | 年度ごとの CBT 公開問題（令和5年度〜令和8年度）科目A / 科目B | 各 4 年度 |
| `fe-sample` | 新制度サンプル問題（2022）科目A / 科目B | 一式 |
| `ext-ap` / `ext-sg` | 応用情報・情報セキュリティマネジメントの関連問題 | 既定で無効 |

出典 URL は手書きせず、`tools/discover.mjs` が IPA のページを巡回して**自動で全件列挙**します
（手書きリストだと題源を取りこぼすため）。結果は `data/sources.json` に入ります。

- **令和2〜4年度（2020〜2022）の CBT 本試験問題は IPA が非公開**です。それらを「真題」と称する外部ソースは信用できないため収録しません。
- 第三者の過去問サイトはこの IPA 公開問題の転載であり、かつ利用規約でスクレイピングを禁じているため取り込みません。

## 2 つの取り込み経路

IPA の PDF は 2 種類あり、扱いを分けています。**どちらの経路でも、問題文を人手や AI で書き起こすことはしません。**

**テキスト経路** — CBT 公開問題・サンプル問題・一部の修了試験。
PDF にテキスト層があるので、問題文と選択肢をそのまま構造化します。マーカーや検索が使えます。

**画像経路** — 本試験 午前と多くの修了試験。これらは**スキャン画像の PDF** でテキストが一切入っていません。
そこで OCR は「問N がページのどこにあるか」を突き止めるためだけに使い、
出題時に表示するのは **PDF の該当領域を切り出した画像そのもの**です。
こうすると OCR が誤読しても、受験者が読む内容は公式 PDF と 1 ドットも変わりません。
OCR テキストは重複判定・検索用にだけ保持し、画面には出しません。

正解はどちらの経路でも、必ず公式「解答例」PDF から取ります（解答例 PDF はテキストが取れます）。

## 出さないための仕組み（検証ゲート）

「実在しない問題を出さない」ことを最優先にしています。以下のいずれかに当たると出題対象から外し、
`data/quarantine/` に理由つきで隔離します。

- 出典（ラベル・PDF URL・ページ番号）が欠けている、または IPA 公式ドメイン以外
- 選択肢ア〜エが揃わない／空がある
- **選択肢の中に別の選択肢の本文が混入している**（テキスト層が壊れた PDF で起きる）
- 日本語が 1 文字ずつ空白で分断されている、文字化けがある
- 解答例 PDF に対応する問番号が無い
- **その回の 8 割未満しかきれいに構造化できない場合、その回はまるごと不採用**
- 画像経路では、OCR で見つけた「問N」が 1..N の連番になっていない回はまるごと不採用

## 重複の名寄せ

修了試験は「60% 以上が本試験の過去問そのまま」と IPA 自身が説明しています。
`tools/dedup.mjs` が正規化テキスト（画像経路は OCR テキスト）で名寄せし、
代表問題に「過去に何回出題されたか」を持たせます。**よく出る問題ほど優先して練習できます。**
迷う類似度のものは統合せず別問題として残します（誤った統合は問題を消してしまうため）。

## リポジトリ構成

```
schema/question.schema.json   問題データの契約（出典必須・改変禁止をスキーマで強制）
tools/                        discover → scan-text → build-text / build-image → dedup → validate
data/                         問題 JSON・切り出し画像・出典レジストリ・隔離された問題
app/                          CBT 模擬試験フロントエンド（Vite + React + TypeScript）
.github/workflows/            import-ipa.yml / import-scanned.yml / deploy-pages.yml
```

## 取り込みを GitHub Actions で動かす理由

開発環境からは `ipa.go.jp` への外向き通信が遮断されているため、
PDF の取得・描画・OCR・解析は **GitHub Actions ランナー上**で実行し、結果を `data/` にコミットします。

- `tools/**` を push すると `import-ipa.yml`（テキスト経路）が走ります
- `tools/build-image.mjs` を push すると `import-scanned.yml`（画像経路、OCR あり）が走ります
  - 取り込む回数は変数 `MAX_EXAMS` で制御します（既定 2 回。精度を確認してから増やす）

## 開発

```bash
npm ci                 # 取り込みツールの依存
npm run validate       # 問題データの検証ゲート

cd app
npm ci
npm run dev            # 開発サーバ
npx playwright test    # CBT 画面の e2e（PC / スマートフォンの 2 ビューポート）
```

GitHub Pages への公開は `deploy-pages.yml` の**手動実行のみ**です
（このリポジトリには既存の Pages サイトがあるため、自動デプロイはしません）。

## 出典と著作権について

IPA は情報処理技術者試験の過去問題について著作権を放棄していませんが、
試験制度の趣旨に反しない教育目的であれば、許諾・使用料なしで利用できるとしています。
その条件として **出典の明示** が求められ、問題を改変した場合はその旨の明示も必要です。

本プロジェクトは、

1. すべての問題に `出典：令和元年度 秋期 基本情報技術者試験 午前 問1` 形式のラベルと、取得元 PDF の URL・ページ番号・SHA256 を保持し、
2. 画面上に必ず出典を表示し、
3. **問題文・選択肢を一切改変しない**（`modified` は常に `false`）

という方針で運用します。解説（中国語）は本プロジェクト独自の非公式なものであり、
正解の根拠は常に IPA 公式の「解答例」PDF です。

参考: [IPA 試験情報 利用規約](https://www.jitec.ipa.go.jp/_termofuse.html) ／ [過去問題](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html) ／ [科目A試験免除制度](https://www.ipa.go.jp/shiken/about/menjo-fe.html)

## 免責

本システムは学習用の非公式ツールです。採点方式（IRT・1,000 点満点・基準点 600 点）は再現しておらず、
表示される正答率はあくまで目安です。最新の試験制度は必ず [IPA 公式サイト](https://www.ipa.go.jp/shiken/) を確認してください。
