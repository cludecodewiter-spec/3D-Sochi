# jpfetest — 基本情報技術者試験（FE）CBT 模擬試験システム

スマートフォンでも PC でも動く、実際の CBT 画面に近い操作感の模擬試験システムです。
**出題は IPA が公式に公開している過去問題のみ**を使用します。問題文は一切改変しません。

> 中文说明：这是一个「基本情報技術者試験」的 CBT 模拟考试系统。**题目全部来自 IPA 官方公开的历年真题**，
> 每一题都带有可追溯的出典（官方 PDF 的 URL + 页码 + SHA256），绝不自行编造题目。

---

## 出題範囲（すべて IPA 公式公開資料）

| プール | 内容 | 既定 |
|---|---|---|
| `fe-honshiken` | FE 本試験 午前（平成21年度 春 〜 令和元年度 秋） | 有効 |
| `fe-menjo` | 科目A試験免除制度の修了試験（特例措置問題） | 有効 |
| `fe-koukai` | 年度ごとの CBT 公開問題（令和5年度〜） | 有効 |
| `fe-sample` | 新制度サンプル問題（2022） | 有効 |
| `ext-ap` / `ext-sg` | 応用情報・情報セキュリティマネジメントの関連問題 | 無効（任意で有効化） |

- **令和2〜4年度（2020〜2022）の CBT 本試験問題は IPA が非公開**です。それらを「真題」と称する外部ソースは信用できないため、本プロジェクトでは収録しません。
- 第三者の過去問サイトはこの IPA 公開問題の転載であり、かつ利用規約でスクレイピングを禁じているため、取り込みません。

## 出典と著作権について

IPA は情報処理技術者試験の過去問題について、著作権を放棄していませんが、
試験制度の趣旨に反しない教育目的であれば、許諾・使用料なしで利用できるとしています。
その条件として **出典の明示** が求められ、問題を改変した場合はその旨の明示も必要です。

本プロジェクトは、

1. すべての問題に `出典：令和元年度 秋期 基本情報技術者試験 午前 問1` 形式のラベルと、取得元 PDF の URL・ページ番号・SHA256 を保持し、
2. 画面上に必ず出典を表示し、
3. **問題文・選択肢を一切改変しない**（`modified` は常に `false`）

という方針で運用します。解説（中国語）は本プロジェクト独自の非公式なものであり、
正解の根拠は常に IPA 公式の「解答例」PDF です。

参考: [IPA 試験情報 利用規約](https://www.jitec.ipa.go.jp/_termofuse.html) ／ [過去問題](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)

## リポジトリ構成

```
schema/question.schema.json   問題データの契約（出典必須・改変禁止をスキーマで強制）
tools/                        取り込みパイプライン（discover → fetch → extract → segment → answers → dedup → validate → report）
data/                         問題 JSON・図版 PNG・出典レジストリ
app/                          CBT 模擬試験フロントエンド（Vite + React + TypeScript, PWA）
.github/workflows/            import-ipa.yml（問題取り込み）/ deploy.yml（GitHub Pages）
```

## 取り込みパイプラインを Actions で動かす理由

開発環境からは `ipa.go.jp` への外向き通信が遮断されているため、
PDF の取得と解析は **GitHub Actions ランナー上**で実行します（`.github/workflows/import-ipa.yml`）。
`tools/**` を push すると自動で走り、結果が `data/` に反映されます。

## 開発

```bash
npm ci          # 取り込みツールの依存
npm run discover  # ※ ipa.go.jp に到達できる環境でのみ動作
npm run validate  # 問題データの検証（出典欠落・選択肢数・解答整合性）
```

## 免責

本システムは学習用の非公式ツールです。合否や採点方式（IRT）は実際の試験とは異なります。
最新の試験制度・出題範囲は必ず [IPA 公式サイト](https://www.ipa.go.jp/shiken/) を確認してください。
