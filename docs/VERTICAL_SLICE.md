# 垂直切片规格：可玩的第一小时

> 范围 = `DESIGN_v12.md` §14 的第 1–4 项。
> 目标：**30–60 分钟真正能玩完**，且含一个明确的情感高点。
> 覆盖回合 **1–12**，结束于「待续」。

---

## 1 切片要证明什么

垂直切片不是 demo，是**风险验证**。这一版要回答三个问题：

1. 四阶段偷车**手感成不成立**？（每段的征兆是否真的让玩家觉得自己在做判断，而不是在掷骰）
2. 情报真假的**背叛时刻打不打得中**？（玩家会不会真的对 Benny 生气）
3. 档案库**是不是真的有用**？（玩家会不会在事后主动打开它去查 Benny）

如果这三个都成立，其余系统只是内容量问题。如果不成立，加再多系统也救不了。

---

## 2 逐回合脚本

| 回合 | 事件 | 解锁 | 用意 |
|---|---|---|---|
| **1** | **教学偷车**：Solomon 在场，目标是一辆 1984 年的车（`classic`，全维度低） | 车辆查看 · 四阶段偷车 · 街头销赃 | 学会核心循环。Solomon 在场 = 公开的 +0.20，四段全部顶到 0.95 上限 |
| 2 | **债主的电话**（`calllog` 形态） | — | 第 7 回合前交 $1,500。压力时钟启动 |
| 3 | **Benny 出现**，给出第一条情报 | 线人与情报 | Solomon：「他为什么要告诉我？」 |
| 4 | 玩家自由行动 | 熟人销赃（第 4 回合起） | 第一次自主决策 |
| **6** | **档案库解锁** | 档案库 | Solomon：「你也该有个本子。」 |
| **7** | **债务结算 #1** | — | 达标 → 松一口气；未达标 → 债主升级 |
| 8 | **Benny 的第二条情报** | — | 这条是**假的**。玩家此时已经信任他 |
| **9** | **背叛兑现** | 热度 | 见 §3。切片的情感高点 |
| 10 | 余波：Marco 受伤，热度上升 | — | 玩家第一次被迫用受损状态行动 |
| 11 | 玩家决定要不要再找 Benny | — | 档案库在这里证明自己 |
| **12** | 债务结算 #2 · 情报验证解锁 → **待续** | 情报验证 | 切片结束 |

> 解锁点是 1 / 3 / 6 / 9 / 12——严格三回合间隔（DESIGN_v12 §8.1）。
> Benny 的两条情报由**出现顺序**而非回合数钉死（第一条必真、第二条必假），
> 所以无论玩家什么时候去找他，背叛都会准时到达。

## 3 情感高点：Benny 的背叛

### 设计

```
BENNY WALSH · 码头工人
  honesty  45   ← 他会骗人
  access   70   ← 而且他知道真相
```

这是 §6.1 四象限里**最危险的一类**：知道真相，却选择卖你假的。
玩家看不到这两个数字。

### 演出

**第 3 回合**，Benny 给出第一条情报，`truth = true`。
玩家照做，成功，赚到钱。**信任建立。** 这一步是必需的——没有信任，就没有背叛。

**第 8 回合**，Benny 给出第二条：

> 「7 号仓库，周四晚上有货。两个看守，都在前门。
>  后面那道卷帘门锁着，但那锁我见过，老式的。」

`truth = false`。

**第 9 回合**，玩家执行。关键在于**征兆会自信地说谎**（§4.3 第 3 条）：

```
【踩点】
  后门那道卷帘门确实是老式的。Benny 没说错。
  你数了数，前门两个人影。

  [ 从后门进 ]  [ 等他们换班 ]  [ 放弃 ]
```

玩家会选「从后门进」——**这在他掌握的信息下是完全正确的判断。**

```
【破解】
  锁开了。比你想的还快。

【脱离】
  仓库里有六个人。
  其中四个，本来就在等你。
```

Marco 肩部中枪，休养 4 回合。

### 事后

第 10 回合玩家再打开档案库，看到的是**自动生成**的（§9.2，不是手写内容）：

```
BENNY WALSH · 码头工人 · 线人
  首次接触：第 3 回合
  提供情报：2 条 | 准确 1 | 错误 1
  累计支出：$450

  第 8 回合 ──「7 号仓库周四有货，两个看守」
    └─ 你执行了偷车
       └─ ❌ 实际有六个。Marco 肩部中枪，休养 4 回合。

  关系：-15
```

**这个因果缩进是沿 `causedBy` 图遍历出来的**，不是任何人写的文案。
如果这一屏成立，档案库的全部设计价值就被证明了。

## 4 内容清单

| 类别 | 数量 | 说明 |
|---|---|---|
| 车辆 | 10 | 6 `classic` / 3 `modern` / 1 `contemporary`（**最后一辆偷不走**，为第三纪埋线） |
| 线人 | 4 | Benny (45/70)、Rosa (80/30)、Teo (30/40)、Marcus (70/75，贵) |
| 情报条目 | ~40 | 真 / 半真 / 假，按线人属性生成 |
| Solomon 顾问台词 | 6 段 | 对应 6 次解锁 |
| 债主电话 | 3 通 | 升级三段 |
| 文档形态 | 6 种 | `calllog` `ledger` `note` `map` `surveillance` `casefile` |
| 程序化美术 | 3 类 | 车辆侧影（5 种车身 × 3 年代）、拼图肖像、城区地图 |
| SegmentRun 配置 | 1 套 | 偷车（4 段 × 3 选项 = 12 个选项 + 征兆模板） |

那辆 `contemporary` 的车必须在第一小时就出现在列表里、看得见、偷不走。玩家会去试。他会失败。**十几个小时之后他才会明白那一刻意味着什么。**

## 5 验收清单

第一小时结束时，玩家必须已经：

- [ ] 成功偷过一辆车（不保证第一次就成——教学关约 81% 通过率，见 DESIGN_v12 §5.3）
- [ ] 失败过一次并逃掉了
- [ ] 拿到了第一笔钱
- [ ] 接到了债主的第一个电话
- [ ] 被 Benny 骗过一次
- [ ] 在档案库里查到过那条错误情报及其后果

工程侧：

- [ ] `npm run typecheck && npm run lint && npm test` 全绿
- [ ] 同一 seed 两次运行结果完全一致
- [ ] 存档往返后 `state` 与 `log` 深度相等
- [ ] `engine/` 与 `systems/` 零 DOM 引用
- [ ] 全部美术为运行时生成，构建产物不含任何图片文件
- [ ] 第 1 天屏幕上只有 2 个可点的东西
- [ ] 第一小时内出现过的控件种类 ≤ 6

## 6 明确不做

Diana 与 Kai 的章节、暗网、加密、围剿、腐败网络、地盘、比赛/运输/追车配置、第二与第三纪。

**DESIGN §7 的四条失败收束线**（借新还旧 / 里面 / 一个人 / 被清算）也不做。
本期只保证失败会**明确通报**（案卷形态的弹窗），且终局失败直接进结局页——
而不是像早先那样默默置一个标志位、游戏若无其事地继续下去。

这些在 `DESIGN_v12.md` 里有完整规格，但**核心手感未验证前不铺开**。
SegmentRun 引擎会按支持四种配置来写，但本期只交付偷车这一份配置。
