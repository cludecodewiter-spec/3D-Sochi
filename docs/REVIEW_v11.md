# 对 v11.0 的复评

> 这份文档记录 v12 每一处改动的**依据**。
> 结论先行：v11 是一份好文档，但它**违背了自己写在第 5 行的原则**，
> 并且遗漏了三块让它无法真正交付给程序部门的内容。

---

## 前置：关于上一份评测

上一份评测给出的判断是：

> "这份策划案完美体现了……通过'动刀最少、收益最高'的外科手术式精准打击"
> "原则清晰：不加新系统，只补短板"
> "是一份可以直接交付美术、程序和文案部门执行的高质量标杆级文档"

**这三句话都需要修正。** 逐条说。

---

## S1｜v11 违背了自己的原则

v11 第 5 行写着：

> **原则：不加新系统，只补短板。**

实际清点修订二与修订三新增的系统：

| 出处 | 新增系统 | 需要的新代码 |
|---|---|---|
| 修订二 A | 比赛分段决策（4 段 × 3 选项 + 对手征兆读取） | 状态机 + 征兆生成器 + 对手 AI |
| 修订二 B | 运输路线事件链（4 段 + 随机遭遇表） | 状态机 + 遭遇池 + 权重表 |
| 修订二 C | 追车三层博弈 + Diana「极限状态」资源 | 状态机 + 意志资源 + PTSD 触发器 |
| 修订三 C | 暗网经营层（声誉养成 / 平台政治 / 退出骗局 / 自营市场） | 一整套经营模拟 |
| 修订三 C | 加密层（脏币追溯链 / 混币成本 / 价格波动持仓 / 出金渠道） | 一整套交易模拟 |
| 修订四 B | 「漫长的一周」7 回合脚本事件链 | 脚本编排器 + 7 组专属内容 |

**净增约 6 个系统、约 +10 小时内容量**（第三纪 15h → 22h，另加第二纪中段的一周）。

上一份评测把这称为「极高的性价比与克制」。它表扬了这份文档没有做到的事。

一次真正的手术应该是：**先合并与删减，再补最小必要的短板。** 这是 v12 的总方针。

### v12 的做法

**S1-a 合并 Diana 的三套子系统。**

比赛、运输、追车在结构上是同一件事：

```
一次多段推进：
  每段 → 呈现征兆（不完整的信息）
       → 玩家做选择
       → 结算并改变持续状态量（车况 / 时间 / 注意度 / 意志）
       → 状态量影响后续段的难度与可选项
最后一段结算总结果
```

Marco 的四阶段偷车**也是这个结构**（踩点 → 接近 → 破解 → 脱离）。

→ v12 抽象出**单一 `SegmentRun` 引擎**。比赛、运输、追车、偷车全部是它的**配置数据**（段定义、选项表、状态量、遭遇池、征兆模板）。

结果：v11 要写 4 套状态机，v12 写 1 套 + 4 份 JSON 式配置。
更重要的是**手感统一** —— 玩家学会一次，四种玩法全都会玩。这同时顺手削掉了一部分上手门槛。

**S1-b 降级暗网与加密。**

它们在 v11 里是两个独立玩法层，但它们真正提供的体验价值是：
- 暗网 = **一种可靠度模型不同的情报来源**（匿名、便宜、更容易是陷阱）
- 加密 = **一条费率与追溯风险不同的销赃通道**

这两句话可以完全用已有的情报系统和经济系统表达，不需要新系统。

删掉：平台政治、自营市场经营链、价格波动持仓、多渠道出金博弈。
保留：**退出骗局**和**钓鱼平台长线埋伏**（第 3 章埋、第 5 章爆）——这两个是纯剧本内容，几乎零系统成本，戏剧性却最高。这正是「动刀最少、收益最高」该有的样子。

## S2｜上手门槛的真解是解锁曲线，不是档案库

v11 判断档案库能把上手门槛从 6.5 拉到 8.0。**档案库确实是好东西，但它救不了新手。**

档案库解决的是「我记不住第 3 小时发生了什么」——这是**第 5 小时之后**的问题。
新手劝退发生在**第 1 到第 3 小时**，那时还没有东西可查，问题是「屏幕上同时有情报网、腐败网、地盘、三人日程，我不知道该看哪」。

v11 对此只写了「第一小时只教三件事」。**第 2 到第 5 小时是空白的。**

### v12 的做法

补一张**全局系统解锁表**。核心约束有三条：

1. 每个系统绑定明确的解锁条件（回合数 / 剧情节点 / 玩家行为），未解锁则 **UI 上完全不存在**，不是灰掉
2. 任一时刻最多只有一个系统处于「刚解锁」状态 —— 新系统之间强制隔开至少 3 个回合
3. 每次解锁必定伴随一个顾问场景（复用 v11 修订五 A 的 Solomon 机制），教学永远由角色说出口

档案库保留，但它在解锁曲线上的位置应该在**第 5–8 回合**，也就是玩家开始真的记不住的时候，而不是一开始就塞给他。

## S3｜视觉方案的优先级是倒的

v11 修订四 A 的三层视觉供给，第二层是：

```
背景层（12） × 天候层（6） × 时段层（4） × 前景元素（20） = 数千种组合
```

两个问题。

**第一，成本被低估了。** 这需要约 42 个独立美术图层，且它们必须在任意组合下都能正确叠加（透视一致、光照一致、遮挡关系正确），外加一个合成器。这不是「成本极低」。

**第二，也是更根本的：它对抗的不是真正的疲劳来源。**

v11 自己诊断的症状是「第 30 小时后我在读纯文字」。这句话的重点不是「画面重复」，是「**永远是一段正文加几个按钮**」——疲劳来自**信息呈现形式的单一**，不是背景图不够多。换一张下雨的仓库背景，玩家读的仍然是同一种版式的同一种段落。

而 v11 把真正的解药——第三层「程序化伪档案（报纸、监控截图、案卷、便条、照片）」——排在了最后，一笔带过。

### v12 的做法

砍掉天候 × 时段的乘积，把预算全部投到**文档形态库**：

| 形态 | 用途 |
|---|---|
| 报纸剪报 | 你的案子上了新闻；结局的剪报集 |
| 监控帧 | 踩点情报、事后被拍到的证据 |
| 通话记录 | 债主的电话、线人联系史 |
| 短信串 | 队友的临场沟通、催债 |
| 账本表格 | 收支、销赃分成、债务利息 |
| 手绘地图 | 踩点成果、路线规划 |
| 警方案卷 | 热度升高后你能看到的自己的档案 |
| 手写便条 | 线人塞给你的纸条、Solomon 的字迹 |

每种是一个 HTML + CSS 渲染模板。**成本比图层合成低一个数量级**，直接对抗真正的疲劳源，而且强化「你在翻一堆档案」这个核心主题气质。

核心插图 60 张保留 —— 那 60 张是有用的，它们服务于关键剧情高点。

## S4｜「故事模式」会杀死主题

v11 修订五 B：

> 【故事】自动处理情报筛选、腐败维护、地盘管理

**自动处理情报筛选** = 替玩家做本作**唯一真正的核心判断**。

v11 自己在「如果只能做五件事」里把「情报真假系统」列为第 3 位，并写下「本作的灵魂」。故事模式把灵魂关掉了。而选故事模式的玩家恰恰是为剧情来的——他们会错过这个游戏最好的剧情体验：*你信错了人，有人因此中枪*。

腐败维护和地盘管理自动化没问题，那些是管理负担。情报筛选不是负担，是**主题本身**。

### v12 的做法

三档只调节**惩罚强度与信息密度**，任何一档都不替玩家判断情报真假：

| | 故事 | 标准 | 硬核 |
|---|---|---|---|
| 情报真假判断 | **玩家做** | **玩家做** | **玩家做** |
| 可靠度评分显示 | 显示 | 显示 | 不显示 |
| 顾问提示 | 常驻 | 关键节点 | 关闭 |
| 失败后果 | 可挽回 | 标准 | 永久 |
| 资金压力 | ×0.5 | ×1.0 | ×1.4 |
| 腐败/地盘维护 | 自动 | 建议 | 手动 |

## S5｜「漫长的一周」应该参数化

v11 修订四 B 的七天固定事件链：手下失踪 → 保护伞被带走 → 货被劫 → Solomon 病倒 → 竞争者提合并 → 手下回来了 → 你必须决定是谁在针对你。

这段写得好。但作为**固定脚本**它有三个问题：

1. **一次性** —— 第二周目完全失效，而 v11 自评重玩价值 9.0
2. **与全案气质冲突** —— 这个游戏其余部分是涌现式模拟，这里突然变成线性演出
3. **不针对玩家** —— 如果玩家根本没建保护伞，Day 2 就是空转

### v12 的做法

改为**「围剿」模板**（Siege）。骨架保留 7 天与最后的指认，但每个 slot 由系统**按玩家当前最薄弱的环节**填充：

| 玩家的疏漏 | 系统填入的打击 |
|---|---|
| 只依赖一个线人 | 那个线人被对手买通，开始喂假情报 |
| 腐败网只有单点 | 那个保护伞被带走 |
| 队友长期过劳 | 他倒下，一周内无法行动 |
| 现金流紧绷无储备 | 一批货被劫，你付不出下周的分成 |
| 情报从不验证 | 你手上一半的情报同时被证伪 |
| 地盘扩张过快 | 边缘地盘同时反水 |

触发条件是玩家实力越过阈值（而不是固定回合数）。

这样每一周目的围剿都不同，**而且打的是玩家自己的疏漏**。主题重量比固定剧本更重：不是「有人在针对你」，是「**你自己留下的每一个口子，现在同时被捅了**」。

## S6｜v11 完全没写的三块

这三块的缺失，正是「可以直接交付程序部门执行」不成立的原因。

### 6-a 失败状态

整份 v11 没有一个字说明玩家**怎么输**、输了之后**是什么**。
一个有债务、有警方热度、有队友伤亡的游戏，不能没有失败定义。

v12 定义四种失败，且**都不是 Game Over 弹窗**，而是各自转入一条收束线（见 DESIGN_v12 §7）。

### 6-b 数值模型

v11 通篇没有一个公式。车辆「防御数值」是什么范围？技能怎么判定？热度怎么衰减？债务利息多少？销赃价怎么算？

没有这些，程序无法开工，策划也无法验证平衡。v12 §5 给出全部公式。

### 6-c 技术规格

状态机、事件总线、存档 schema、版本迁移 —— 全部缺失。v12 §9 补齐。

## S7｜Kai 的三条路里，[拒] 是伪选项

v11 修订三 A：

```
[拒] 坚持老方法。成功率极低，但如果做到了——
     专属文本 + 一个只有这条路能拿到的成就
```

「成功率极低」意味着这条路在**数值上是错的选择**。玩家会点进去、失败几次、然后回去选 [学] 或 [用]。这个分支的内容将被 95% 的玩家浪费掉。

而这条路在主题上本该是最重的那条 —— Marco 拒绝被时代改造。把它做成一次运气判定，是在浪费全案最好的一个题眼。

### v12 的做法

[拒] 改为**可行、但改变游戏形态**：

放弃现代车，专攻 **2005 年前的老车**。这是一个真实存在的细分市场：
- 铁丝和撬棍在这些车上**依然 100% 有效**，Marco 的技能不打折
- 但单车利润只有现代车的 40–60%
- 而且这个池子**逐章萎缩**：第三纪每推进一章，可下手的老车数量下降

于是「坚持」从一次掷骰变成一个**有代价的经济策略**：你能一直靠它活着，只是你的世界一年比一年小。

主题也因此更准。时代不会让你失败 —— 时代只是让能容下你的地方越来越少。这比「成功率极低」心碎得多。

## S8｜删掉自评分表

v11 结尾的「修订后预期评分 9.0」是自我背书：没有评测者，没有样本，分数由作者自己给出。

v12 换成**可验证的验收标准**（DESIGN_v12 §10），例如：

- 新手在 60 分钟内完成首次销赃闭环，全程未打开外部资料
- 第 5 小时的玩家能正确答出「上一条错误情报是谁给的」
- 单局内出现 ≥ 6 种不同的文档形态
- 第二周目的围剿事件组合与第一周目重合度 < 50%

这些能测。分数不能。

## 复评汇总

| 编号 | 结论 | v12 手术 | 方向 |
|---|---|---|---|
| S1 | 违背「不加新系统」原则 | Diana 三系统合并为 SegmentRun；暗网/加密降级 | **减法** |
| S2 | 档案库救不了新手 | 补全局解锁曲线 | 补短板 |
| S3 | 视觉优先级倒置 | 砍图层乘积，投文档形态库 | **减法 + 换向** |
| S4 | 故事模式杀死主题 | 三档只调惩罚强度 | 修正 |
| S5 | 漫长的一周一次性 | 参数化为围剿模板 | 改造 |
| S6 | 缺失败状态/数值/技术规格 | 全部补齐 | 补短板 |
| S7 | [拒] 是伪选项 | 改为萎缩的老车市场 | 修正 |
| S8 | 自评分无依据 | 换为可验证验收标准 | 修正 |

**净效果：删掉的系统比新增的多。** 这才是 v11 声称、但没有做到的那次手术。
